## 一、项目信息

| 字段 | 值 |
|---|---|
| **项目名称** | dreampulse |
| **技术栈** | Next.js 全栈 (App Router + SSR) + Tailwind CSS，部署 Cloudflare Pages |
| **品牌调性** | 追求梦想 · 科技感 · 深色系（深蓝/黑底 + 蓝紫渐变 accent） |
| **一句话定位** | 面向全球用户的 AI 驱动新闻聚合平台，用科技连接每一个追梦人的信息世界 |

### 原始需求复述

DreamPulse 是一个 AI 驱动的新闻聚合平台，早期以 AI 摘要聚合模式运营（爬取中英文公开新闻源 → AI 改写为摘要 → 标注原文链接），后期开放 UGC 用户自由发布图文/视频内容。平台覆盖科技、社会、情感、明星八卦、音视频、体育、成人七大版块，其中成人版块需实名/手机号年龄认证后解锁。核心用户功能包括注册登录、评论回复、点赞收藏、关注、社交分享、自主发布。后台需支持内容审核、用户管理、版块管理、数据看板。先做中英双语，自动检测 + 手动切换，后续扩展。部署在 Cloudflare Pages，利用 SSR 天然 SEO 优势 + 社交分享实现用户增长。

## 二、产品目标

### 产品愿景

成为全球用户获取 AI 精炼资讯的首选平台——让每个人在海量信息中，用最短时间获取最有价值的内容，同时通过社区互动连接志同道合的追梦人。

### 三大核心目标

| # | 目标 | 衡量指标 |
|---|---|---|
| G1 | **AI 内容聚合效率** — 用户用更少时间获取等量信息 | 平均单篇阅读时长 < 60s；AI 摘要点击原文率 > 15% |
| G2 | **全球可访问性与 SEO 增长** — 通过 SSR + CDN 实现全球低延迟 + 搜索引擎收录 | 首屏加载 < 1.5s（全球 P75）；Google/百度收录页面 > 10k / 月 |
| G3 | **社区互动与留存** — 从消费内容到参与社区 | 注册用户 7 日留存 > 30%；日人均互动（评论+点赞+收藏）> 3 次 |

## 三、用户故事

### 核心用户画像

| 画像 | 描述 | 核心诉求 |
|---|---|---|
| **资讯快消者** | 25-35 岁，关注科技/社会热点，时间碎片化 | 快速获取精炼摘要，不被信息淹没 |
| **社区参与者** | 20-30 岁，乐于表达与社交 | 评论互动、关注话题、分享到社交平台 |
| **内容创作者** | 自媒体/博主，有原创内容输出需求 | 发布内容、获得曝光、积累粉丝 |
| **国际用户** | 英语为主的海外用户 | 无障碍访问、自动语言切换、内容无地域限制 |

### 关键用户故事

1. **As a** 资讯快消者，**I want to** 在首页看到 AI 精炼的新闻摘要，**so that** 我能在 1 分钟内了解一条新闻的核心信息。
2. **As a** 社区参与者，**I want to** 对新闻发表评论并收到回复，**so that** 我能和志同道合的人交流观点。
3. **As a** 内容创作者，**I want to** 在平台上自主发布图文内容，**so that** 我的作品能被更多追梦人看到。
4. **As a** 国际用户，**I want to** 打开网站自动显示英文界面并阅读英文内容，**so that** 我无需手动切换语言即可顺畅使用。
5. **As a** 成人用户，**I want to** 通过实名认证后访问成人版块，**so that** 我能在合规前提下获取该类内容。

## 四、需求池

### P0 — MVP 必须

| 编号 | 需求 | 说明 |
|---|---|---|
| P0-01 | AI 新闻摘要聚合 | 爬取中英文公开新闻源 → AI 改写摘要 → 标注原文链接；支持定时/触发式更新 |
| P0-02 | 七大版块展示 | 科技、社会、情感、明星八卦、音视频、体育、成人 — 首页 Tab / 侧栏导航 |
| P0-03 | 用户注册/登录 | 邮箱 + 密码注册；支持第三方 OAuth（Google、GitHub） |
| P0-04 | 新闻列表与详情页 | 卡片流列表 → 点击进入摘要详情页（含原文链接） |
| P0-05 | SSR + SEO | Next.js App Router SSR，动态 meta / Open Graph 标签，sitemap.xml，robots.txt |
| P0-06 | 中英双语 | 浏览器语言/IP 自动检测 + 右上角手动切换；内容按语言分源聚合 |
| P0-07 | Cloudflare Pages 部署 | 全站部署 Cloudflare Pages，利用全球 CDN |
| P0-08 | 成人版块年龄认证 | 手机号验证码认证年龄（≥18岁）后解锁访问，未认证用户不可见该版块内容 |
| P0-09 | 响应式深色主题 | 深蓝/黑底 + 蓝紫渐变 accent，移动端/桌面端自适应 |

### P1 — 重要但可延后

| 编号 | 需求 | 说明 |
|---|---|---|
| P1-01 | 评论与回复 | 对新闻/帖子发表评论，支持楼中楼回复 |
| P1-02 | 点赞与收藏 | 对内容点赞/收藏，个人中心查看收藏列表 |
| P1-03 | 关注系统 | 关注作者/话题，首页 Feed 展示关注内容 |
| P1-04 | 社交分享 | 分享到 Twitter/X、微信、WhatsApp 等，含 Open Graph 预览图 |
| P1-05 | 后台内容审核 | AI + 人工审核队列，敏感词过滤，举报机制 |
| P1-06 | 后台用户管理 | 用户列表、封禁/解封、角色权限 |
| P1-07 | 后台版块管理 | 版块增删改、排序、显隐控制 |
| P1-08 | 后台数据看板 | UV/PV、热门内容、用户增长趋势、版块流量分布 |

|---|---|---|

## 五、UI 设计参考

### 整体风格

- **主题**：深色科技感 — 追求梦想的夜空意象
- **主色**：深蓝 `#0A0E27` / 纯黑 `#000000` 交替底色
- **强调色**：蓝紫渐变 `#4F46E5 → #7C3AED`（按钮、链接、高亮）
- **文字**：白/浅灰 `#F1F5F9` 主文字，`#94A3B8` 辅助文字
- **卡片**：半透明深色 `rgba(15,23,42,0.8)` + 微弱边框 + 悬停发光效果

### 页面结构

| 页面 | 说明 |
|---|---|
| **首页** | 顶部导航栏（Logo + 版块 Tab + 语言切换 + 登录按钮）→ 焦点区（AI 精选大卡片）→ 瀑布流新闻卡片列表 |
| **版块页** | `/section/tech` 等，单版块下的新闻列表，支持分页/无限滚动 |
| **详情页** | AI 摘要正文 + 原文链接 + 评论区域 + 相关推荐 |
| **个人中心** | 我的收藏、我的评论、关注的作者/话题 |
| **后台管理** | 侧栏导航（审核/用户/版块/看板）→ 数据表格 + 图表 |

### 交互规范

- 版块切换无刷新，SPA 路由切换 + 动画过渡
- 新闻卡片悬停：微上浮 + 边框渐变发光
- 列表加载：骨架屏 + 无限滚动
- 语言切换：即时生效，URL 保持不变（Cookie 存偏好）

## 六、待确认问题

| # | 问题 | 影响范围 | 建议 |
|---|---|---|---|
| Q1 | AI 摘要改写的法律合规性 — 是否需获得原新闻源授权？ | 内容策略 | 早期仅做摘要+标注原文链接，不做全文转载，风险较低；建议法务确认 |
| Q2 | 新闻爬取频率与源站反爬策略如何处理？ | 技术架构 | 需评估 RSS/API 优先 + Headless Browser 兜底方案 |
| Q3 | 成人版块的具体合规要求 — 是否需要 ICP 备案 / 内容分级标签？ | 法律合规 | 需根据部署地（Cloudflare 全球）确认适用法规，建议咨询法律顾问 |
| Q4 | AI 改写使用的模型 — 自部署 vs API 调用？成本预估？ | 技术选型 | 建议先 API（OpenAI / Claude），后续量大再考虑自部署 |
| Q5 | 用户数据存储方案 — Cloudflare D1 / KV / 外部数据库？ | 技术架构 | 需架构师评估 Cloudflare 生态内方案 vs PlanetScale/Supabase 等 |
| Q6 | 成人版块的年龄认证 — 是否需要对接第三方实名认证服务？ | 产品功能 | 手机号验证码可初步满足；如需更严格认证需对接第三方 |
| Q7 | UGC 开放时间节点 — MVP 后多久上线？ | 产品规划 | 建议 MVP 上线后 1-2 个月，先验证聚合模式 PMF 再开放 UGC |
